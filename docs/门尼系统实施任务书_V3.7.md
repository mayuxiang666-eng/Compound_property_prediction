## 1. 做完长什么样

- NSSM `MooneyPredictService` 每 **2s 轮询**：MMS 曲线就绪 → **成功才** INSERT `MooneyResult`；失败写 **Miss**
- Vue 每 **5s** 读 `/api/Health` + `/api/MooneyBatches/Recent`
- 详情：漏斗 S1/1b/S2/Raw/Offset/Final、专家 FLOAT、精选特征、曲线（**MixingInfo**）
- `LabStatus=PENDING`；`CalibrationOffset` 多为 **0**（State 空壳已建，Predict 会读）
- **浏览器不调 Python / 不连 MMS 推理**
- 本阶段定位：**影子预测**（验证覆盖率/延迟/数据质量），不以「2s 出数」为 SLA

---

## 2. 方法摘要（对照总规格）

```text
BatchID     = str(int(BatchNumber))
Mixer       = Orders.Equipment
可预测      = Curve1/Curve2 非空 **且** 解码点数≥10（对齐 extract_features_for_row）
物料占比    = OrderMaterials
LabelGroup  = OrderID|PalletID 或 OrderID|NOPALLET|{BatchID}
ProductTime = 优先 MixingInfo；同源 XML Time 才 +8h
缺特征      = 填 0.0（**与训练/打包一致**，不改 median）
Final       = Raw + State.BiasOffset（无 State → 0；禁止当前 Lab）
失败        = 不写 Result，写 MooneyPredictMiss
已有行      = PK 冲突跳过，不覆盖
轮询        = 2s；SLA = 就绪→写入延迟分位数（另测）
```

参考代码：`predict_latest_sfe_order.py`、`HybridUnifiedMooneyModel.predict`；打包后**必须改掉** stub 里对当前 MNY 的校准。

### 本版谁调谁

| 谁 | 何时 | 做什么 |
|----|------|--------|
| PredictService | 2s | MMS + 写 `MooneyResult`（非 HTTP） |
| Vue 列表 | 5s | Health + Recent |
| Vue 详情 | 进页 | 详情 + `/curve` + `/features` |
| ASP.NET | 响应 GET | 只读 SQL（含 MixingInfo 曲线） |

本版不做：`/lab`、Calibration 写入、Kpi/Trust。
