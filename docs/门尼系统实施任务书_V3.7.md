## 1. 本版目标（做完长什么样）

- NSSM `MooneyPredictService` 每 **2s** 扫 MMS：曲线就绪车次 → 写 `MooneySystem`
- IIS/本机：Vue 每 **5s** 只读 `/api/Health` + `/api/MooneyBatches/Recent`
- 详情可看：五灯、漏斗 S1/1b/S2/raw/offset/final、专家条、曲线、特征 Tab
- `lab_status=PENDING`；`calibration_offset` 通常 **0**（表已建空壳，Predict 已会读 state）
- **浏览器绝不调 Python / 不连 MMS 推理**

## 2. 本版方法（对齐仓库预测逻辑）

### 2.1 参考代码（照抄模式，勿发明）

| 步骤 | 参考文件 |
|------|----------|
| 连接 HF_MMS/SFEPLANT | `pipeline_orchestrator.connect_mms_encrypted` 或 `predict_latest_sfe_order.connect_mms` |
| 曲线就绪 SQL / OrderMaterials pivot | `model_analysis/predict_latest_sfe_order.py` → `query_latest_order_rows` |
| Mixer 字段 | `predict_order_v3.py`：`Orders.Equipment AS MixerLine` → 入库 `mixer_id` |
| 模型 | `HybridUnifiedMooneyModel.predict` → `(uncal,s1,s1b,s2)` |
| 专家 | `_transform_process_deltas` + `SilicaSubsystemPredictor.predict_experts` / CB 同理 |
| 打包 | `save_production_v37_model_package.py`（**必须改掉** stub 里对当前 MNY 的 `calibrate_time_series`） |

### 2.2 字段映射（摘要，全文 §2.5）

```text
batch_id   = str(BatchNumber)
mixer_id   = Orders.Equipment
可预测     = Curve1 IS NOT NULL AND Curve2 IS NOT NULL
物料占比   = OrderMaterials（不是 BatchMaterials 主路径）
label_group= OrderID|PalletID 或 OrderID|NOPALLET|{batch_id}
缺特征     = 填 0.0
final      = raw + SQL(calibration_state.bias)   # V3.7 无 state → 0
```

### 2.3 本版 API 调度

| 谁 | 何时 | 调什么 |
|----|------|--------|
| PredictService | 每 2s | MMS SELECT + 写 MooneySystem（**非 HTTP**） |
| Vue Monitor | 每 5s | `GET /api/Health` + `GET /api/MooneyBatches/Recent?minutes=240` |
| Vue 进详情 | 一次+可选刷新 | `GET .../MooneyBatches/{o}/{b}` + `/curve` + `/features`（诊断再加 `/debug`） |
| Vue Health 页 | 进页/轮询 | Health + 可选 Models/Active |
| ASP.NET | 仅响应上述 GET | 只读 SQL |

本版**不实现**：`/lab`、Calibration、Kpi、Trust 写入（详情里 `lab`/`trust` JSON 键保留为 `null`）。
