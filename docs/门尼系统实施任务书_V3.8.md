## 1. 做完长什么样

- Lab 延迟到达 → 按 **托盘组** 回填 `MooneyResult` 的 Lab*；**不改历史 Final**
- Adaptive EWMA 写 `MooneyCalibrationState` → **下一车** Predict 读到新 Offset
- 同 `LabelGroupId` 校准 **只 1 次**；`NOPALLET` 可展示 Lab、**不**更新 State
- 前端：Lab 状态、误差、同组车次、校准页

---

## 2. 托盘规则（本版核心）

```text
有盘: LabelGroupId = OrderID|PalletID
无盘: LabelGroupId = OrderID|NOPALLET|BatchID

Lab 到 → UPDATE 组内每一行 LabActualMny（同值）+ 各车 RawError/OnlineError
      → Queue 只 INSERT 一行（代表车）
Engine → 更新 State；旧行 Final/Offset 不动
NOPALLET → 不进有效校准（REJECTED/NOPALLET_NO_CALIB）
```

状态：`PENDING → MATCHED → VALIDATED → CONSUMED`，或 `REJECTED`。

α 表（总规格 §6.6）：0.60 / 0.40 / 0.25 / 0.15；变点 `|Δe|≥2`；offset clip ±4。  
**不用**离线 calibrator 的 0.65/0.20。

### 谁调谁

| 谁 | 何时 | 做什么 |
|----|------|--------|
| LabCalib（或第二 Timer） | 300s | Datamart → Matcher → Engine |
| Vue 详情 | 进页 | 加 `/lab` 或详情内嵌 `.lab` |
| Vue 组面板 | 按需 | `ByLabelGroup/{labelGroupId}` |
| Vue 校准页 | 进页 | `Calibration/States` + events |
| 列表 | 仍 5s | 多显示 labStatus / labActualMny / errors |

Predict 仍 2s；只是读到的 BiasOffset 可能非 0。
