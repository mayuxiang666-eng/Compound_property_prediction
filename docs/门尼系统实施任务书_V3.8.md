## 1. 本版目标

- Lab 延迟到达后匹配历史预测；**不改历史 final**
- Adaptive EWMA 写入 `calibration_state`；**下一车** Predict 读到新 offset
- 同 `label_group` 只校准 **1 次**；`NOPALLET` 可展示 Lab、**不**更新 state
- 前端：Lab 状态机、误差、`/mooney-calibration`

---

## 2. 本版方法

### 2.1 相对 V3.7 只加什么

| 层 | 叠加 |
|----|------|
| 服务 | `lab_source_datamart` + `lab_matcher` + `calibration_engine`；α=`calibration_alpha.json`（总规格 §6.6） |
| 表 | 写 queue/state/event；UPDATE log 的 lab_*/error/lab_status |
| API | `/lab`、`ByLabelGroup`、`Calibration/States`、`.../events`；Recent 填 lab 字段；详情 `.lab` |
| UI | Lab 列/卡；校准页；`VITE_HAS_LAB_MODULE=true` |

线上 α **不用** 离线 `Stage3DelayedFeedbackCalibrator` 的 0.65/0.20（附录 D）。

### 2.2 状态推进

```text
PENDING → MATCHED → VALIDATED → CONSUMED
                 ↘ REJECTED
```

`final` / `raw` / `offset`（预测当时快照）**永不改**。

### 2.3 本版 API 调度

| 谁 | 何时 | 调什么 |
|----|------|--------|
| LabCalib 服务（或 Predict 第二 Timer） | 每 **300s** | Datamart 拉 Lab → Matcher → Engine（写 SQL） |
| Vue 详情 | 进页 | 在 V3.7 详情请求外加 `GET .../lab`（或读详情内嵌 `.lab`） |
| Vue 组面板 | 按需 | `GET .../ByLabelGroup/{labelGroupId}` |
| Vue 校准页 | 进页/刷新 | `GET /api/Calibration/States`；点行再 `.../States/{id}/events` |
| Vue 列表 | 仍 5s Recent | 多显示 labStatus / labActualMny / errors（键在 V3.7 已预留） |

Predict 热路径 **不变**：仍每 2s；只是读到的 `bias_offset` 可能非 0。
