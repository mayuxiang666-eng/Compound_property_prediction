## 1. 做完长什么样

- Lab 延迟到达 → 按 **托盘组** 回填 `MooneyResult` 的 Lab*；**不改历史 Final**
- 校准误差用 **`Lab − mean(Raw)`**（对齐评估；**禁止代表车**）；同组 Queue **只 1 次**
- 默认 **影子校准**（算候选 / Event，不自动写 ACTIVE Bias），回放门禁后再有限自动
- `NOPALLET` 可展示 Lab、**不**更新 State
- 前端：Lab 状态、误差、同组车次、校准页

---

## 2. 托盘规则（本版核心）

```text
有盘: LabelGroupId = OrderID|PalletID
无盘: LabelGroupId = OrderID|NOPALLET|BatchID

Lab 到 → UPDATE 组内每一行 LabActualMny（同值）+ 各车行级 RawError/OnlineError
      → GroupRawError = Lab − mean(Raw_i)   # 校准只用这个
      → Queue INSERT 一行（带 LabSourceKey；库级幂等）
Engine → UPDLOCK 事务更新 State；旧行 Final/Offset 不动
影子  → Status=SHADOW 或不写 Bias；Predict 仍用旧/0 offset
NOPALLET → 不进有效校准（REJECTED/NOPALLET_NO_CALIB）
复测  → 已 CONSUMED 禁止二次校准
```

状态：`PENDING → MATCHED → VALIDATED → CONSUMED`，或 `REJECTED` / `SKIPPED_DUP`。

α 表（总规格 §6.6，**生产策略**）：0.60 / 0.40 / 0.25 / 0.15；  
`Δe = GroupRawError − LastConsumedGroupRawError`，`|Δe|≥2`；单次 `|Δbias|≤1.5`；offset clip ±4。  
与 Python `Stage3DelayedFeedbackCalibrator`（CompoundName + α≈0.65/0.20）**有意不同**，见总规格 §1.0。

## 4. 验收勾选

- [ ] 同托盘多车 LabActualMny 相同，各车行级误差可不同
- [ ] Queue 使用 **GroupRawError = Lab−mean(Raw)**，非代表车
- [ ] 同 LabelGroup / LabSourceKey 仅 1 条有效 NEW 或 CONSUMED
- [ ] State 更新在事务+行锁下完成
- [ ] 历史行 Final/Raw/Offset 未被 UPDATE
- [ ] NOPALLET 有 Lab 展示、State 不变
- [ ] 影子模式：Predict 不因候选 Event 自动改 Bias（直至显式开启）
- [ ] 回归 V3.7：心跳、恒等式、Miss、失败不写 Result
