## 1. 做完长什么样

- 详情顶卡：分数、HIGH/MED/LOW、区间、原因码
- 列表置信度列；页 `/mooney-kpi`
- Trust **只 UPDATE** 置信度相关列；不碰预测冻结列

---

## 2. 写库顺序（锁死）

```text
V3.7 INSERT MooneyResult（冻结漏斗/专家）
  → TrustEngine（读精选特征 + 可选 State/Lab）
  → UPDATE 仅 confidence* / interval* / reason*
禁止改 Raw/Final/Offset
```

### 谁调谁

| 谁 | 何时 | 做什么 |
|----|------|--------|
| PredictService | 写库成功后 | 进程内 Trust（非前端） |
| KpiAggregator | 每日 | 写 `MooneyKpiDaily` |
| Vue | 详情/列表/KPI 页 | 只读 ASP.NET |
