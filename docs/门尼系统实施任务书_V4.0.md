## 6. 最小 Trust / KPI 契约（增补；可独立验收）

> Hybrid 包内无 Trust 源码；本表为工程最小契约，实施时落 `trust_weights.json` / KPI SQL。

### 6.1 Trust 六维（缺维 → null，合成时跳过并重归一化）

| 维 | 输入概要 | 备注 |
|----|----------|------|
| 特征完整 | CompletenessRatio | |
| 路由稳定 | MaterialSystem/PhaseRoute 是否落入训练路由 | |
| 校准新鲜 | State.NFeedback / LastUpdateTime | 无 State → n/a |
| Lab 一致 | 有 Lab 时 \|OnlineError\| | 无 Lab → n/a |
| 专家一致 | 专家贡献是否异常尖峰 | |
| 工艺门 | 关键 phys/Stage 是否过硬门 | |

合成：加权平均 → `confidenceScore` 0–100；映射 HIGH/MED/LOW；`intervalLow/High` 须满足 `intervalLow ≤ Final ≤ intervalHigh`（有区间时）。

### 6.2 KPI 口径（`MooneyKpiDaily`）

| 指标 | 口径 |
|------|------|
| n_pred / n_with_lab | 当日 Result 行数 / LabStatus 已匹配行数 |
| raw_mae / online_mae | 有 Lab 行上 \|RawError\| / \|OnlineError\| 均值 |
| miss_rate | Miss 行 / (Result+Miss) |
| reject_count | Queue REJECTED |
| low_conf_rate | confidenceLabel=LOW 占比（有 Trust 后） |
