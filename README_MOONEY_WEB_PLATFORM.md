# Continental 终胶密炼过程曲线与门尼全车次智能预测平台 (v2.0)
## Continental Final Mix Mooney Intelligence Platform

本系统将终胶密炼曲线前向物理推断、11 阶段工艺窗口特征工程、全车次门尼偏差自动化预测以及多维交互可视化完整固化为标准化 Web 模板应用。

---

### 一、核心架构与特性

1. **实时双库联动数据总线 (Zero Data Leakage Pipeline)**：
   - **SFE 生产云数据库 (`HESFESFEPLANT`)**：直连拉取 `BatchHeader`（车次总数、托盘映射、时间跨度、混炼用时、单车重量）与 `BatchCurve`（Curve1 胶温、Curve2 功率、Curve3 累计能量、Curve5 扭矩、Curve6 转子转速、Curve7 顶栓位移）。
   - **Redshift 质量分析集市 (`he_datamarts.compound_excellence_datamart`)**：按 `order_id` 与 `pallet_id` 实时检索实验室 `ML1+3` 门尼检验真值。若有质检数据则自动叠加对验；若无化验记录（如工单 `7045560`），自动进入**纯盲测前向物理推断模式**。

2. **全工单 1 ~ N 所有车次自动分析与演化追踪**：
   - 不仅支持首车（Batch 1）与尾车（Batch N），系统自动计算工单内**每一车次**相对于基准车的门尼偏差预测值 $\Delta\widehat{\text{Mooney}}_i$。
   - 过滤排料后空转假象，提取**真实有效混炼均值功率 ($P_{\text{active}}$)**、上密炼功率 ($P_{\text{up}}$)、下密炼功率 ($P_{\text{low}}$) 与累计机械做功 ($E_{\text{discharge}}$)。
   - 多模型协同推断：**有效剪切 Huber 模型**、**4 阶段无共线物理模型**、**综合集成预测值 (Consensus)**，并标注 $\pm 1.5\text{ MU}$ 行业公差带。

3. **任意双车次深度对比与 11 阶段物理机理归因**：
   - 交互式下拉菜单：支持任意选择基准车（Batch A）与目标车（Batch B）进行一对一微观解构。
   - **11 阶段工艺窗口物理量对照表**：逐段对比温度演变、功率、转速、顶栓位移、物理机理解释与阶段门尼贡献。
   - **门尼偏差瀑布分解图 (Waterfall Attribution)**：量化截距基准、初温影响、二段捏合、排料剪切、有效总剪切功对总门尼偏差的独立推动力。
   - **五维曲线逐秒同步对比**：功率、温度、累计电耗、顶栓轨迹、转速步进，以及逐秒偏差曲线 $\Delta P(t)$ 与 $\Delta T(t)$。

4. **全车次明细报表与 CSV 导出**：
   - 包含全车次初温、排胶温、功率、做功、时长及各模型预测门尼值，支持一键导出为标准 CSV 报表。

### 二、快速启动与访问方式

#### 方式 1：双击桌面/目录批处理脚本（推荐）
直接在当前工作目录双击运行：
👉 **`启动终胶门尼分析平台.bat`**
脚本将自动启动后台服务并在默认浏览器中直接打开：
🌐 **`http://127.0.0.1:5050`**

#### 方式 2：终端命令行启动
```powershell
python app.py
```
随后在浏览器中输入 `http://127.0.0.1:5050` 即可访问。
