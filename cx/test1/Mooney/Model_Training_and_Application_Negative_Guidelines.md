## 一、 顶层定位与三大铁律（最高技术宪章）

在密炼机 ML09 门尼粘度与能耗建模的所有生命周期中，必须无条件服从以下三大铁律：

### 铁律一：坚决杜绝“工艺调参/给设定值建议”方向
* **【绝对禁止】**：
  * 向用户、车间工艺员或上位机输出任何“建议将时间增加20秒”、“建议调节转速至65 RPM”、“建议调温3度”等工艺配方修改建议或调机口诀。
* **【唯一定位】**：**纯粹的数据驱动【数学与机器学习模型】**。模型输出被严格圈定在以下三项：
  1. **正向精准估测**：输出门尼粘度估测值 (Mooney_pred) 与 单车总能耗估测值 (Energy_pred)；
  2. **物理因果相关性矩阵**：输出工艺与过程状态变量对目标值的简单 Pearson r 与控制全流程干扰后的纯净 Partial r；
  3. **突发异常根因解构**：输出异常来源的数学三层解构（是工艺执行偏差、机台工况漂移，还是原料生胶批次残差）。

### 铁律二：100% 原始数据驱动，零幻觉、零手工加减字典
* **【绝对禁止】**：
  * 人工手工编写任何“生胶门尼高1点时间就加3秒”、“转速每加5转能耗加0.8度”的硬编码加减字典；
  * 直接把样本全局均值、中位数、众数或规程静态标准数字作为基准值。
* **【正向要求】**：所有权重、斜率、阈值和流变基准，必须 100% 从工厂确证生产数据（LabelInPallet == True）中直接拟合、逆向流变解析或损失极小化动态求解得出。

### 铁律三：全步序累积与严格物理隔离盲测，禁止推倒重来与随机打乱
* **【绝对禁止】**：
  * 遇到指标瓶颈随意推翻历史物理成果；
  * 使用随机打乱（Random Shuffle）进行训练集/测试集划分。
* **【正向要求】**：必须严格按工单（OrderID）实施 70:30 物理时序隔离盲测，模拟对未来全新未知订单的真实外推。

## 二、 阶段一：数据输入与预处理负面清单（从源头切断污染）

```
+-----------------------------------------------------------------------------------+
|                            【输入端核心禁区】                                     |
| 严禁将未确证托盘、试生产废品数据混入训练集；严禁缺失值直接盲目全局填补 0 或 均值！ |
+-----------------------------------------------------------------------------------+
```

### 1. 严禁混入未质检确证数据（非 LabelInPallet）
* **禁止操作**：直接全表读取 MMS 数据，不进行 `LabelInPallet == True` 过滤即参与模型训练。
* **后果**：密炼车间在换批、洗机或传感器试机时的废品车次会污染训练集，引入巨大的虚假离群噪声。

### 2. 严禁对物理传感器缺失值盲目填充全局均值或 0
* **禁止操作**：使用 `df.fillna(df.mean())` 或 `df.fillna(0)` 填充排胶温度、转矩或做功能量。
* **后果**：温度填 0 或填均值会完全破坏热力学平衡方程，导致模型在计算温升速率时产生严重的假梯度。
* **正向操作**：传感器掉线车次必须作物理工况剔除，或采用基于前后车次曲线的时间序列局部样条插值。

## 三、 阶段二：基准构建与先验假设负面清单（坚决推翻均值/中值/众数）

```
+-----------------------------------------------------------------------------------+
|                        【天然生胶离散事实（实测数据）】                           |
| 历史工单天然胶实测跨度：最低 47.54 MU（软胶批），最高 74.36 MU（硬胶批）          |
| 极值极差高达 26.82 MU！月度均值在 53.5 MU ~ 63.8 MU 之间随季节剧烈漂移。          |
+-----------------------------------------------------------------------------------+
```

### 1. 严禁直接使用全局静态均值 (Mean)、中位数 (Median) 或众数 (Mode) 作为门尼基线
* **禁止操作**：直接取历史整体平均值（如 59.2 MU）或中位数作为所有车次的默认基准 M0。
* **坚决禁止的原因**：
  * 面对硬胶工单（实测 72.2 MU）：使用静态 59.2 MU 基准直接产生 **-13.0 MU 的致命系统性报亏**；
  * 面对软胶工单（实测 47.5 MU）：使用静态 59.2 MU 基准直接产生 **+11.7 MU 的致命系统性虚高**；
  * 均值基准彻底掩盖了不同批次生胶的真实流变特性，是前序盲测“情况太差”的根本元凶。
* **强制正向做法**：基线必须通过以下两种算法动态计算：
  1. **工业容差极小化迭代器 (L-BFGS-B Solver)**：将基线 M0 与中心工况作为优化变量，在线迭代求解使合格带覆盖率最大的数学基准；
  2. **密炼早期咬料流变逆向解析方程**：利用密炼前 30 秒机械阻力力矩峰值、做功比能率与瞬时温升速率，单车动态解算出每车胶料的生胶流变起始基线。

### 2. 严禁写死规程纸面标准数字
* **禁止操作**：直接读取工艺卡上的理论目标（如 52.0 MU）硬编码进模型当做参考原点。
* **后果**：纸面数字是理想化目标，完全脱离现场设备磨损、原料含水率及环境温湿度的真实物理平衡点。

## 四、 阶段三：特征工程与因果挖掘负面清单（绝无经验字典与时序穿透）

### 1. 严禁未来数据穿越（Data Leakage / Look-ahead Bias）
* **禁止操作**：
  * 在特征工程归一化（StandardScaler）或分箱时，使用全量数据（包含测试集/验证集）拟合均值与方差；
  * 预测第 N 车门尼时，直接引用了第 N 车排胶后化验室在 2 小时后才录入的滞后特征。
* **后果**：制造虚假的超高离线精度，一旦线上实时前瞻预测立即崩溃。
* **正向操作**：预处理器仅在训练集拟合（Fit），测试集仅执行转换（Transform）；前瞻输入必须严格限制在密炼结束前已知工艺与状态特征。

### 2. 严禁人工硬编码“师傅调机经验规则字典”
* **禁止操作**：在代码里写：
  ```python
  # 绝对严禁出现的硬编码
  if mooney_high:
      time_adjust = +20
  ```
* **后果**：经验字典无法适应不同胶料配方与机台损耗，充斥主观幻觉，违背数据驱动原则。

### 3. 严禁把高基数工单号直接作为分类特征喂给树模型
* **禁止操作**：将 `OrderID` 做 One-Hot 或 LabelEncoding 直接输入 LightGBM/CatBoost。
* **后果**：模型机械记忆历史工单编号，对新工单完全没有泛化预测能力。
* **正向操作**：将工单转化为配方组成特征（胶料大类、炭黑比重、软化剂含量、标准能量预算等通用连续特征）。

## 五、 阶段四：损失函数与优化训练负面清单（绝不搞对称盲目拟合）

### 1. 严禁盲目使用标准对称均方误差 (MSE / RMSE) 作为单一损失函数
* **禁止操作**：`loss = mean((y_true - y_pred)**2)` 贯穿始终。
* **坚决禁止的原因**：
  * 工业门尼存在明确的**考核死区容差带**：误差在 <= ±1.0 MU 内为免惩罚黄金带；在 1.0 ~ 3.0 MU 内为合格可控带；一旦突破 ±3.0 MU，轮胎胶料降级报废风险呈几何倍数剧增；
  * 对称 MSE 对 0.6 MU 误差和 3.2 MU 误差的相对敏感度分布不合理，模型会为了缩小密集区的微小方差而放弃对出界极端样本的强力约束。
* **强制正向做法**：必须使用**工业死区非对称损失（Deadzone-Huber Loss）**：在合格带内部给予平滑容忍，在超过 ±3.0 MU 临界线后启动强力二次梯度惩罚。

### 2. 严禁允许“反物理因果单调性”的无约束参数更新
* **禁止操作**：模型在训练中学习出“排胶做功能量越高、剪切做功越多，排胶门尼粘度反而越高”的异常正梯度。
* **后果**：严重违背高分子聚合物受剪切发热机械降解的物理规律，导致后续灵敏度矩阵输出荒谬结论。
* **强制正向做法**：在损失函数中增加物理因果正则项（PINN 单调性惩罚），强行约束做功能量与转速时间的主效应偏导数 <= 0。

### 3. 严禁无早停机制的强行长轮次迭代过拟合
* **禁止操作**：固定迭代 1000 轮，不监控验证集残差，不设 Early Stopping。
* **后果**：传感器高频随机扰动与机械电气噪声被模型深度记忆，导致模型方差爆炸。

## 六、 阶段五：模型输出与应用交付负面清单（坚决杜绝调参建议）

```
+-----------------------------------------------------------------------------------+
|                        【交付物红线：三大严禁 vs 三大必须】                       |
+-----------------------------------------------------------------------------------+
| [X] 严禁输出工艺调机口诀          --> [V] 必须输出正向数值预测 (带 ±3.0 容差区间) |
| [X] 严禁越俎代庖建议修改设定值    --> [V] 必须输出纯净偏相关性与因果灵敏度矩阵    |
| [X] 严禁给出黑盒无解释决策        --> [V] 必须输出突发异常数学三层解构归因        |
+-----------------------------------------------------------------------------------+
```

### 1. 严禁输出任何“工艺设定值修改推荐”
* **禁止行为**：
  * 输出字段包含：`suggested_time`, `rpm_recommendation`, `adjust_temp`；
  * 生成“操作建议：建议下机增加30秒”、“工艺提示：提高主转速5转”。
* **为什么绝对禁止**：
  * 车间生产安全与工艺规程极其严密，密炼机操作受硫化防焦烧窗口、配方密炼规程、主机功率过载保护等多重物理强约束；
  * 数据科学家模型越俎代庖给出调参建议，不仅极易引发生产事故（超温焦烧），而且彻底偏离了“数据驱动正向预测与归因分析”的核心使命。

### 2. 必须交付的标准输出三件套（工业标准定义）
任何模型或 API 接口的最终返回，必须严格限定为：
1. **预测值及其工业置信带**：
   * `Mooney_pred`，并标注是否在 `[Target - 3.0, Target + 3.0]` 容差带内；
   * `Energy_pred`，并标注是否在 `[Target - 2.0, Target + 2.0]` kWh 容差带内。
2. **因果与相关性参考矩阵**：
   * 各可调工艺参数（时间、转速）与响应变量（温度、能量、力矩）的简单 Pearson 相关系数与控制全流程后的偏相关系数（Partial r）。
3. **异常三层解构归因诊断**：
   * 当实测值或预测值超标时，解构为：
     * `delta_execution`（车间工艺执行时间/转速偏差贡献量）；
     * `delta_machine`（机温/冷却水工况波动贡献量）；
     * `delta_raw_material`（生胶批次漂移残差贡献量）。

## 七、 阶段六：验证评估与交叉检验负面清单（绝无随机打乱与虚假高分）

### 1. 绝对禁止随机打乱交叉验证 (Random Shuffle K-Fold)
* **禁止操作**：使用 `train_test_split(..., shuffle=True)` 打乱所有批次车次数据。
* **为什么坚决禁止**：
  * 密炼机生产以“工单（OrderID）”为批次单位，同一工单连续生产 10 ~ 30 车，生胶来自同一进厂批次。
  * 随机打乱意味着测试集中包含了同工单相邻车次的微观信息，模型只需死记该工单局部常数即可在测试集上取得虚假的高达 95% 达标率；
  * 一旦推向车间面对未知新工单，合格率直接断崖式下跌至 40% ~ 50%。
* **强制正向做法**：严格按照工单维度执行 **70:30 物理隔离时序留出验证（Strictly Out-of-Order / Out-of-Time Blind Split）**，训练集与测试集工单零交集。

### 2. 严禁仅靠全局单一 R2 或全局平均 MAE 报喜不报忧
* **禁止操作**：只汇报“测试集整体 R2 = 0.85，整体平均 MAE = 1.8 MU”，隐藏分段指标。
* **坚决禁止的原因**：
  * 整体指标往往被中间 80% 的平稳配方掩盖，真正决定车间质量生死的 10% 极端软胶与 10% 极端硬胶表现被平滑忽略。
* **强制正向做法**：必须同时提供：
  1. **核心合格达标率**：误差在 `<= ±3.0 MU` 内的车次百分比（考核底线，须 >= 90%）；
  2. **黄金合格达标率**：误差在 `<= ±1.0 MU` 内的车次百分比；
  3. **极端切片性能**：生胶实测门尼 `< 52.0 MU`（软胶批）与 `> 65.0 MU`（硬胶批）子集的独立达标率与最大绝对偏差（Max Error）。

## 八、 阶段七：在线推理与部署运行负面清单（绝不裸奔与静态僵化）

### 1. 严禁模型静态部署、永不自适应校准
* **禁止操作**：把离线训练好的 `.pkl` 丢到服务器后台常驻半年不更新。
* **后果**：机械磨损（密炼转子间隙变大）、温控管道结垢传热变差、天然生胶随季节切换产地，静态模型会在投运 2~4 周后逐渐产生稳态单向漂移。
* **强制正向做法**：部署轻量级在线滚动校准闭环（Online Rolling Calibration），利用每天化验室回传的确认数据动态微调流变逆向解析补偿常数。

### 2. 严禁无边界保护直接输出非物理值
* **禁止操作**：模型推理遇到传感器离群跳针时，直接输出负门尼或大于 150 MU 的荒谬预测。
* **强制正向做法**：配置工业物理防护笼（Safety Bounding Box）：
  * 门尼粘度硬性截断在合理物理域 `[30.0 MU, 110.0 MU]`；
  * 单车总能耗硬性截断在合理设备域 `[15.0 kWh, 65.0 kWh]`；
  * 当输入特征超出训练分布 3 个标准差（Mahalanobis Distance 超标）时，系统主动抛出“工况超出置信域”告警，而非输出盲目预测。

| :--- | :--- | :--- | :--- | :--- |
| **顶层定位** | 模型使命 | 严禁给出任何工艺调参/修改设定值建议 | 严格限定在：正向预测 + 偏相关矩阵 + 异常根因解构 | [ ] 合规 |
| **顶层定位** | 纯数据驱动 | 严禁人工硬编码经验规则加减字典 | 100% 数据拟合、逆向解析或优化迭代得出 | [ ] 合规 |
