## 1. 项目最高技术宪章与定位边界

在橡胶工业混炼过程中，工艺参数（转速、时间、温度、扭矩）与最终成品质量（门尼粘度）及资源消耗（单车总电耗）之间存在高度非线性和热力学耦合。

为确保系统符合车间生产安全与工程严谨性，项目确立以下三大技术铁律：

```text
========================================================================================
【最高技术宪章】
1. 绝对禁止输出“工艺设定值调整建议”：
   - 严禁向用户输出诸如“建议上机提速5转”、“建议增加混炼20秒”等调机操作指令；
   - 现场工艺调整受配方设计与安全规范限制，模型专注于“已知输入下的客观前瞻推演”。
2. 唯一定位：纯数据驱动的物理因果响应模型
   - 输入：各步序设定参数（转速、时间、温度、加料逻辑）及机台初始状态；
   - 输出 1：门尼粘度前瞻预测值 (带 ±3.0 MU 置信区间)；
   - 输出 2：单车总能耗前瞻预测值 (带 ±2.0 kWh 置信区间)；

========================================================================================
```

### 2.1 混托污染的物理危害剖析
在轮胎与橡胶制品工厂的常规物流中，为了提升搬运效率，通常将连续混炼的 3~5 车胶料堆叠压实至同一个铁托盘（Pallet）上，化验室仅在托盘表层剪取一块胶样进行门尼分析。
- **混托后果**：测得的门尼实际上是这 3~5 车的“模糊物理混合值”，平滑掉了单车参数微调（如某车提速 5 rpm 或微调 5 秒）的微观物理响应，导致模型训练时信噪比急剧下降；
- **解决对策**：从 MMS 底层批次报头（`raw.MmsBatchHeaderHistory`）与化验库（`core.LabCurrent`）实施严密关联，仅筛选托盘起始车号等于结束车号且批次计数为 1 的样本：
  `PalBatchMin == PalBatchMax & PalBatchCount == 1`

## 3. 基础基准获取的两大逻辑缺陷深度剖析与车间真实解法

在以往的讨论中，曾有关于“首车化验作为基础门尼”以及“前20秒传感器经验公式反解”的设想。经过严密的现场机理与生产事实比对，必须在此明确指出这两套逻辑存在的严重漏洞，并确立真正自洽的工业解法：

### 3.1 逻辑漏洞一：“首车门尼必然存在论”的生产事实破产
- **生产实际**：橡胶车间并非车车送检，而是严格实行**稀疏抽检制**（例如每班抽检第 8 车或第 14 车，甚至全订单只抽检 1 托）。
- **事实破产点**：绝大多数工单的“第 1 车”根本没有化验室门尼数据；且即使首车送检，化验室制样、恒温、测试全流程需 45~90 分钟，等结果出来时整单胶料早已混炼完毕。
- **结论**：**将“首车实测门尼”假设为已知输入作为基准，在逻辑上完全脱离工厂实际，绝不可行！**

### 3.2 逻辑漏洞二：“前20秒经验线性回归反解”的物理流变机理破产
- **曾有设想**：试图用固定经验线性公式反解基准门尼：`base_mooney = 45.70 + 0.0686*T_start + 0.001486*Torque`，以及能耗 `22.0 + 0.065*Total_Time`。
- **机理破产点**：
  1. **冷热机剧烈干扰**：开机冷机时腔壁冷，胶料硬，初始峰值扭矩虚高；热机连续混炼时胶料软，初始扭矩偏低，单一经验公式在冷热机切换时误差超过 8 MU；
  2. **上顶栓与咬胶物理不确定性**：前 20 秒胶料处于不规则大块撕裂咬合阶段，扭矩波动剧烈（标准差超 800 Nm），并非稳定的层流流变状态；
  3. **配方胶种本构差异**：天然胶、顺丁胶、丁苯胶的门尼本构迥异，固定常数无法跨胶种通用；
  4. **能耗非线性**：不同配方电机额定功率与工况负载不同，单纯把时间乘系数完全脱离了电做功积分本质。

### 3.3 核心架构决策：否定方案 A，全面确立【B + C 融合方案】作为唯一生产落地架构

通过现场生产工程师的明确指正，我们对方案进行严格取舍：
- **方案 A（配方标准靶向法）完全不可行**：配方卡上的设计目标值（`MNYTarget`）在工厂中纯属纸面名义参数，受天然生胶批次漂移、填料水分、混炼室磨损等影响，**在日常实际生产中完全没有参考价值**！
- **最高工程共识**：**全面融合【方案 B（稀疏化验继承） + 方案 C（纯差分因果灵敏度）】，构建 B+C 统一架构**。

```text
========================================================================================================
【B + C 统一工业架构：稀疏化验动态继承 (B) + 纯差分物理因果灵敏度 (C)】
========================================================================================================

1. 核心数学公式：
   当前车次预测门尼 = [最近一次有效化验真实实测值 M_last_lab (带温差修正)]
                     + (dMooney/drpm)   * (当前转速 - 上次转速)
                     + (dMooney/dt_mst) * (当前上机时间 - 上次上机时间)
                     + (dMooney/dt_msb) * (当前下机时间 - 上次下机时间)
                     + (dMooney/dTemp)  * (当前排胶温度 - 上次排胶温度)

   当前车次预测能耗 = [最近一次有效车次真实电耗 E_last]
                     + (dEnergy/drpm)   * (当前转速 - 上次转速)
                     + (dEnergy/dt_mst) * (当前上机时间 - 上次上机时间)
                     + (dEnergy/dt_msb) * (当前下机时间 - 上次下机时间)

   • 场景一 (工艺未改，连续生产) : 
     各步序变动量为 0，预测值直接继承最近一次有效化验值（加上机台冷热机温差衰减修正）；
   • 场景二 (现场调参，工艺微调) : 
     利用 C 模块固化的物理导数 (-0.6200 MU/rpm 等)，实时精确计算因参数变动带来的门尼与电耗偏离；
   • 场景三 (化验报告迟来 / 稀疏出样) : 
     无论化验室何时出结果（如第 8 车或 3 小时后），系统自动以真实值更新基准锚点，平滑吸收残差。

3. 架构优势：
   ★ 绝不假定“首车必须有化验”；
   ★ 绝不依赖纸面名义配方目标 A；
   ★ 绝不用固定经验粗暴拟合；
   ★ 100% 依托最近客观真实化验 + 确定性一阶物理流变规律。
========================================================================================================
```

### 4.1 全步序相关性物理规律剖析
1. **下密炼 (MSB) 门尼相关性最高 (-0.268 ~ -0.284)**：
   为什么下密炼步序的相关系数显著高于上密炼？
   - **物理机理**：下密炼是全流程的**最终成型与排胶工位**。上密炼完成初炼后排入下机，下机 MSB 的停留时间与终点做功直接“锁死”了胶料的最终分子量分布和终态流变结构，后续无任何缓冲工序。因此 MSB S1~S3 对成品化验门尼具有最直接、最强的决定性相关度（r 达 -0.284，能耗做功相关度达 -0.285）。
2. **上密炼关键反应区：S6~S7 机械强剪切 + S9~S10 热工硅烷化反应**：
   - `MST_S7` 是全机扭矩最大（峰值超 8000 Nm）、功率最高阶段，提供宏观大分子机械断链的主要动能；
   - `MST_S9` 是温度突破 155℃ 的热工拐点，白炭黑/硅烷体系在该阶段完成剧烈的偶联化学反应，能量对门尼的相关度高达 `-0.253`，门尼粘度在此阶段发生断崖式流变软化。
3. **上机转速在各步序均对总能耗呈负相关 (r = -0.41 ~ -0.52)**：
   - 转速越高，机械摩擦产热速率越快，物料提前达到排胶温度设定点，使单车全周期总用时缩短，机台空载损耗与散热损失减少，从而在整体上节省净电耗。

## 6. 全步序能耗与做功物理守恒模型

单车总能耗不是简单的全局经验公式，而是全步序电机做功积分与热焓转化的守恒叠加：

$$
E_{\text{total}} = E_{\text{anchor}} + \sum_{i=1}^{14} \left[ \left(\frac{dE}{dt}\right)_i \cdot \Delta t_i + \left(\frac{dE}{drpm}\right)_i \cdot \Delta n_i + \left(\frac{dE}{dTemp}\right)_i \cdot \Delta T_i \right]
$$

- **做功强度分级**：
  1. **下机均化段 MSB_S1 (`dE/dt = +0.205 kWh/s`)**：下密炼满载运转功率高达 700~900 kW，每延长 10 秒下机时间，直接增加 **2.05 kWh** 电耗；
  2. **上机高剪切段 MST_S7 (`dE/dt = +0.180 kWh/s`)**：上密炼电机峰值做功区，每延长 10 秒增加 **1.80 kWh**；
  3. **加料与过渡段 (MST_S1, S4, S11)**：电机处于空载/轻载状态，`dE/dt <= 0.015 kWh/s`，做功贡献极微。

## 7. 模型数学形态与可执行全步序架构 (B + C 统一生产架构)

该模型彻底告别“仅含个别变量”的简易方程，全面升级为**全步序工艺设定值关联模型**，严格结合 **化验室稀疏化验锚点继承 (B)** 与 **全步序差分物理因果灵敏度矩阵 (C)**。

### 7.1 显式全步序 B + C 统一预测方程式

对任意生产车次 $k$，其门尼粘度与单车总能耗的计算方程式为：

```text
===================================================================================================================
【全步序门尼粘度前瞻预测方程式 (All-Step Setpoint Model)】
===================================================================================================================

Predicted_Mooney = M_last_lab + sum_{i=1}^{14} [ alpha_i * Delta_t_i + beta_i * Delta_rpm_i + gamma_i * Delta_temp_i ]

其中：
  • M_last_lab   : 该配方最近一次有效化验室真实门尼实测值 (若无上批次化验，由初期流变阻力方程动态生成)；
  • Delta_t_i    : 第 i 步设定时间差量 (秒) = 当前批设定值 Time_SP(i) - 基准批设定值 Time_Base(i)；
  • Delta_rpm_i  : 第 i 步设定转速差量 (rpm) = 当前批设定值 Rpm_SP(i) - 基准批设定值 Rpm_Base(i)；
  • Delta_temp_i : 第 i 步设定排胶/触发温度差量 (℃) = 当前批设定值 Temp_SP(i) - 基准批设定值 Temp_Base(i)；
  • [alpha_i, beta_i, gamma_i] : 第 5 节全步序物理因果灵敏度导数矩阵对应系数。

门尼 95% 工业合格置信区间 : [ Predicted_Mooney - 3.0 MU,  Predicted_Mooney + 3.0 MU ]

===================================================================================================================
【全步序单车总能耗前瞻预测方程式 (All-Step Setpoint Model)】
===================================================================================================================

Predicted_Energy = E_last + sum_{i=1}^{14} [ eta_i * Delta_t_i + theta_i * Delta_rpm_i + lambda_i * Delta_temp_i ]

其中：
  • E_last       : 上一车次真实电表计量电耗 (kWh)；
  • [eta_i, theta_i, lambda_i] : 第 5 节全步序能耗做功灵敏度导数矩阵对应系数。

能耗 95% 工业合格置信区间 : [ Predicted_Energy - 2.0 kWh,  Predicted_Energy + 2.0 kWh ]
===================================================================================================================
```

## 9. 突发异常三层数学归因解构机制

当现场某车胶料门尼突然偏离指标（如门尼冲高至 72 MU 或骤降至 48 MU 时），模型提供纯数学残差归因，绝不猜测：

```text
门尼总偏差 (ΔM_total) = 工艺设定偏差项 + 机台工况扰动项 + 原料批次残差项

1. 第一层：工艺参数执行偏离贡献
   ΔM_process = -0.620 * (rpm - rpm_set) - 0.599 * (t_mst - t_mst_set) ...
2. 第二层：初始机温与机械摩擦扰动贡献
   ΔM_machine = +0.1905 * (T_start - T_start_ref) ...
3. 第三层：上游原料本质波动残差 (Residual)
   ΔM_raw_rubber = M_actual - (M_baseline + ΔM_process + ΔM_machine)
```
- 若 `|ΔM_process|` 占主导：判定为**现场操作/步序执行失调**；
- 若 `|ΔM_raw_rubber|` 显著异常（如 > 8.0 MU）：模型自动出具凭证，证明该偏差系**上游天然生胶来料固有粘度异常**，避免操作人员背锅。
